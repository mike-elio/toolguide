# Phase 5 HTTP API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the validated knowledge snapshot and deterministic recommendation service through the four phase-five FastAPI endpoints.

**Architecture:** Add a strict in-memory `KnowledgeSnapshot` boundary that phase six can populate without changing HTTP contracts. Assemble one phase-five `APIRouter` through dependency-injected application state, keep handlers limited to HTTP translation, and delegate recommendation logic to the existing service.

**Tech Stack:** Python 3.12, FastAPI 0.141.1, Pydantic 2.13.4, CLIPSpy 1.x, pytest 8.x, ReportLab/pypdf for the tracked PDF.

**Spec:** `docs/superpowers/specs/2026-08-24-phase5-api-design.md`

## Global Constraints

- Phase five implements API contracts and orchestration only; JSON loading remains phase six.
- Preserve the existing `snake_case` Pydantic JSON contract and strict `extra="forbid"` behavior.
- Keep all list responses deterministic by stable identifier.
- Reuse the existing HTTP error envelope and never expose internal exception details.
- Route handlers must not reproduce CLIPS, ranking, or explanation logic.
- The default application contains no hard-coded sample knowledge.
- Do not add dependencies, authentication, persistence, pagination, benchmark normalization, or benchmark tie-breaking.
- The tracked PDF must retain the original five pages and phase-four appendix, then add exactly one phase-five appendix.

Create `app/knowledge/models.py`:

```python
from typing import Self

from pydantic import Field, model_validator

from app.domain.models import Benchmark, DomainModel, Question, Rule, Stage, Tool


class KnowledgeSnapshot(DomainModel):
    stages: list[Stage] = Field(default_factory=list)
    tools: list[Tool] = Field(default_factory=list)
    questions: list[Question] = Field(default_factory=list)
    rules: list[Rule] = Field(default_factory=list)
    benchmarks: list[Benchmark] = Field(default_factory=list)

    @model_validator(mode="after")
    def validate_unique_ids_and_references(self) -> Self:
        collections = {
            "stage": self.stages,
            "tool": self.tools,
            "question": self.questions,
            "rule": self.rules,
            "benchmark": self.benchmarks,
        }
        for label, items in collections.items():
            ids = [item.id for item in items]
            if len(ids) != len(set(ids)):
                raise ValueError(f"{label} ids must be unique")

        stage_ids = {stage.id for stage in self.stages}
        tool_ids = {tool.id for tool in self.tools}
        questions_by_id = {question.id: question for question in self.questions}

        for question in self.questions:
            if question.stage not in stage_ids:
                raise ValueError(f"question references unknown stage: {question.stage}")
        for rule in self.rules:
            question = questions_by_id.get(rule.question_id)
            if question is None:
                raise ValueError(f"rule references unknown question: {rule.question_id}")
            if rule.answer_option_id not in {option.id for option in question.options}:
                raise ValueError(
                    f"rule references unknown answer option: {rule.answer_option_id}"
                )
            for impact in rule.impacts:
                if impact.tool_id not in tool_ids:
                    raise ValueError(
                        f"rule impact references unknown tool: {impact.tool_id}"
                    )
        for benchmark in self.benchmarks:
            if benchmark.tool_id not in tool_ids:
                raise ValueError(
                    f"benchmark references unknown tool: {benchmark.tool_id}"
                )
        return self
```

Export only `KnowledgeSnapshot` from `app/knowledge/__init__.py`.

```python
from typing import Annotated, cast

from fastapi import Depends, Request

from app.knowledge import KnowledgeSnapshot
from app.recommendations import RecommendationService


def get_knowledge(request: Request) -> KnowledgeSnapshot:
    return cast(KnowledgeSnapshot, request.app.state.knowledge)


def get_recommendation_service(request: Request) -> RecommendationService:
    return cast(RecommendationService, request.app.state.recommendation_service)


KnowledgeDependency = Annotated[KnowledgeSnapshot, Depends(get_knowledge)]
RecommendationServiceDependency = Annotated[
    RecommendationService, Depends(get_recommendation_service)
]
```

Create `app/api/routes.py` with `APIRouter()` and typed response models:

```python
@router.get("/stages", response_model=list[Stage])
def list_stages(knowledge: KnowledgeDependency) -> list[Stage]:
    return sorted(knowledge.stages, key=lambda stage: stage.id)


@router.get("/stages/{stage}/questions", response_model=list[Question])
def list_stage_questions(
    stage: StageId, knowledge: KnowledgeDependency
) -> list[Question]:
    if stage not in {item.id for item in knowledge.stages}:
        raise HTTPException(status_code=404, detail="Stage not found")
    return sorted(
        (question for question in knowledge.questions if question.stage == stage),
        key=lambda question: question.id,
    )


@router.get("/tools/{tool_id}", response_model=Tool)
def get_tool(tool_id: Identifier, knowledge: KnowledgeDependency) -> Tool:
    tool = next((item for item in knowledge.tools if item.id == tool_id), None)
    if tool is None:
        raise HTTPException(status_code=404, detail="Tool not found")
    return tool
```

Modify `create_app` to accept keyword-only optional dependencies, store them on

Create `app/api/contracts.py`:

```python
from typing import Self

from pydantic import Field, model_validator

from app.domain.models import DomainModel
from app.expert_engine import AnswerSelection


class RecommendationRequest(DomainModel):
    answers: list[AnswerSelection] = Field(min_length=1)

    @model_validator(mode="after")
    def validate_unique_questions(self) -> Self:
        question_ids = [answer.question_id for answer in self.answers]
        if len(question_ids) != len(set(question_ids)):
            raise ValueError("answer question ids must be unique")
        return self
```

- [ ] **Step 4: Implement the POST orchestration**

Add to `app/api/routes.py`:

```python
@router.post("/recommendations", response_model=RecommendationResult)
def recommend(
    request: RecommendationRequest,
    knowledge: KnowledgeDependency,
    service: RecommendationServiceDependency,
) -> RecommendationResult:
    if len(knowledge.tools) < 3:
        raise HTTPException(status_code=503, detail="Knowledge base is not ready")
    try:
        return service.recommend(
            tools=knowledge.tools,
            questions=knowledge.questions,
            rules=knowledge.rules,
            answers=request.answers,
        )
    except KnowledgeValidationError as error:
        raise HTTPException(status_code=422, detail=str(error)) from error
```

Do not catch unexpected expert-engine or recommendation consistency exceptions; the
existing global handler must convert them to the safe 500 envelope.
